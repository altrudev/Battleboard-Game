# Battleboard Game

Battleboard Game is the gameplay and content project built on Battleboard Engine.

Core game systems include recruitment, scouting, training, roster construction, board-position aptitude, affinity and predisposition, relationships, progression, tournament qualification, arenas, story, equipment, injuries, and campaign content.

The engine repository owns reusable runtime technology. This repository owns the specific game rules, content, progression, balance, characters, and presentation.
